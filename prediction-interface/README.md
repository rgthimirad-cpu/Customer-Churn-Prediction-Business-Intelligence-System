##### **Customer Churn Prediction System**

##### **Group 6 - Prediction Interface / Prototype**



**Project Overview**



The Customer Churn Prediction System is a machine learning-powered web application designed to predict whether a customer is likely to discontinue a company's services. The application serves as the final prediction interface of the Customer Churn Prediction \& Business Intelligence System project.



This component enables business users to enter customer information through an interactive web interface and receive an instant churn prediction generated by the trained machine learning model. In addition to the prediction result, the system provides customer risk classification, churn risk factors, and actionable retention recommendations to support customer retention strategies.



The application is developed using Streamlit and integrated with the final machine learning pipeline produced during the model development phase of the project.







**Objectives**



The main objective of this prototype is to provide a user-friendly interface that allows non-technical users to:



\- Enter customer information.

\- Generate churn predictions in real time.

\- Identify customers with high churn risk.

\- Understand key churn drivers.

\- Receive suitable retention recommendations.

\- Support business decision-making using predictive analytics.







**Key Features**



**Customer Data Input Interface**



Allows users to enter customer profile, service subscription, and billing information through a structured form.



**Machine Learning Model Integration**



Integrates the trained customer churn prediction model and preprocessing pipeline for automatic prediction generation.



**Churn Probability Prediction**



Calculates the probability of customer churn as a percentage.



Example:



Churn Probability: 84.7%

Risk Classification

Classifies customers into risk categories:

•	LOW Risk

•	MEDIUM Risk

•	HIGH Risk

Risk Factor Identification

Highlights major customer characteristics contributing to churn risk.

Example:

\- Short tenure

\- Month-to-month contract

\- High monthly charges

Retention Recommendation Engine

Provides suitable actions based on predicted risk level.

Examples:

\- Personalised retention offer

\- Loyalty incentives

\- Customer engagement campaigns

User-Friendly Dashboard

Displays prediction results, risk indicators, and recommendations in an easy-to-understand format.

**Prediction Workflow**

1\.	User enters customer information.

2\.	System validates the input values.

3\.	Engineered features are automatically generated.

4\.	Input data is passed to the machine learning model.

5\.	Churn probability is calculated.

6\.	Risk level is determined.

7\.	Risk factors are identified.

8\.	Retention recommendations are generated.

9\.	Results are displayed to the user.
